An entry for the make.fun bounty: https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba

A micro-confession in exactly two parts: a To: line naming who it was meant
for, and the unsent message itself, one line written exactly as it was typed,
with no explanation after it.

`main.py` (pure Python standard library) writes the confession to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, byte-identical on every run.
